# عوالم العشق الأبدي | لعيون شادية 💖🚗
### Shadia's Love Road - Romantic 2D Web Game

لعبة قيادة سيارات رومانسية مخصصة ومصممة خصيصاً كإهداء لخطيبتي الغالية **«شادية»**.

---

## 🌟 مميزات اللعبة:
- 🛣️ **4 عوالم رومانسية خلابة**:
  1. **بوليفارد الورود والغروب 🌹**: أسفلت داكن، أحواض ورد، وأشجار كرز وردية.
  2. **طريق الساحل وبحر العشق 🌊**: شاطئ بأمواج بحر متحركة، رمال ذهبية، وأشجار نخيل.
  3. **ليل النجوم واليراعات الساحرة ✨**: ليل مخملي داكن، يراعات مضيئة تومض في الظلام، وأشجار سحرية.
  4. **واحة الخريف الذهبي 🍁**: ألوان عنبرية دافئة وأشجار قيقب متساقطة الأوراق.
- 💌 **50 عبارة شعرية وغرامية مخصصة لشادية**: رسالة عشق ملكية مخملية بختم الشمع الأحمر تظهر عند التقاط قلوب الياقوت.
- 🚗 **تخصيص ألوان السيارة**: إمكانية التبديل بين 4 ألوان (الأحمر الملكي، الوردي الفاتن، الذهبي، والفيروزي) مع كشافات زينون، باقة ورد 99 زهرة، ولوحة تحمل اسم **`شـاديـة ❤️`**.
- 🎵 **محرك صوتي وسيمفوني رومانسي (Web Audio API)** مدمج بدون ملفات خارجية.
- 📱 **تصميم مخصص للهواتف الذكية (Mobile-First Experience)**:
  - ملء الشاشة بنسبة 100% بدون هوامش أو شريط تمرير (`100dvh`).
  - دعم السحب المباشر بالإصبع على الشاشة للتوجيه بدقة وسلاسة (Touch & Drag Steering).
  - أزرار لمس جانبية سفلية مريحة للإبهام مع **اهتزاز تفاعلي (Haptic Feedback)** عند الانعطاف أو التقاط القلوب.
  - دعم النوتش والشاشات الحديثة للآيفون والأندرويد (`safe-area-insets`).
- 🚀 **تطبيق ويب تقدمي (PWA Capable)**: يمكن إضافته للشاشة الرئيسية للهاتف ليعمل كتطبيق مستقل بملء الشاشة.
